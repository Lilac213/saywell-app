# 智能回复助手需求文档

## 1. 应用概述

### 1.1 应用名称
智能回复助手

### 1.2 应用类型
iOS原生应用

### 1.3 应用描述
一款基于iOS辅助功能的智能聊天回复助手，通过截图聊天记录快速生成个性化回复建议，帮助用户在社交场景中更高效地沟通。

## 2. 核心功能
\n### 2.1 快捷截图触发
- 用户通过iOS自带辅助功能（小圆点/AssistiveTouch）一键截取聊天记录
- 截图后自动弹出应用页面，展示回复建议

### 2.2 用户画像构建

#### 2.2.1 初始问卷
- 首次使用时引导用户填写问卷
- 问卷可跳过，用户可选择稍后填写或直接进入上传聊天框
- 问卷包含以下内容：
  - 性格偏向问题（提供多个选项供用户选择，如：外向/内向、理性/感性、严谨/随性、幽默/严肃等）
  - MBTI性格类型\n  - 星座信息
  - 语言习惯相关问题（如：标点符号使用习惯、断句习惯、常用语气词等）
  - 其他个性特征识别问题

#### 2.2.2 特征分析与存储
- AI分析问卷结果，提取用户特征
- 将用户画像数据存储至数据库\n- 分析内容包括：性格特点、语言习惯（含标点符号、断句习惯）、人格特征等

#### 2.2.3 持续学习优化
- 在用户后续使用过程中，不断收集聊天场景和用户选择的回复
- 每次生成回复时，提供第四条回复选项为'以上都不合适，我要自定义'，用户可填写反馈或自定义回复内容
- 根据用户反馈和自定义内容，更新用户画像（包括语言习惯、标点符号使用、断句偏好等）
- 在下一次聊天分析中应用学习到的新特征

### 2.3 智能回复生成
- 基于用户画像和当前聊天内容，AI生成多个符合用户风格的回复选项
- 准确识别回答者和问题者角色，确保回复内容符合用户身份
- 精确分析用户的语言习惯，包括标点符号使用频率、断句方式、语气词偏好等
- 用户可从多个回复建议中选择合适的内容
- 支持一键复制或直接发送回复

### 2.4 历史记录管理
- 保存用户的历史聊天记录和回复选择
- 历史记录保存条数可由用户在设置中自定义（默认保存最近100条）
- 支持查看和删除历史记录
\n## 3. 技术要点

### 3.1 iOS辅助功能集成
- 调用iOS AssistiveTouch功能实现快捷截图
- 截图后自动唤起应用界面

### 3.2 图像识别\n- 识别截图中的聊天文本内容
- 提取对话上下文信息
- 准确区分对话中的回答者和问题者角色\n
### 3.3 AI分析引擎\n- 分析用户问卷，建立初始画像
- 根据用户画像和聊天内容生成个性化回复
- 精确分析语言习惯，包括标点符号、断句、语气词等细节特征
- 持续学习用户行为和反馈，优化画像模型
- 优化分析速度，提升响应效率

### 3.4 数据存储与部署
- 存储用户画像数据
- 记录用户历史选择和聊天场景\n- 使用中国境内可访问的后端数据库服务（如阿里云数据库、腾讯云数据库等）
- 调用中国境内可用的AI API服务（如阿里云通义千问API、腾讯云混元API、百度文心一言API等），确保无需VPN即可正常使用

## 4. 设计风格
- 配色方案：以清新的浅蓝色为主色调，搭配白色背景和深灰色文字，营造简洁专业的视觉感受
- 界面布局：采用卡片式布局，回复选项以独立卡片形式呈现，便于快速浏览和选择
- 视觉细节：圆角弧度为8px，卡片带有轻微阴影增强层次感，图标采用线性风格保持统一性\n- 交互动效：弹出页面采用从下向上的滑入动画，选择回复时有轻微的点击反馈效果
