# 智能回复助手需求文档

## 1. 应用概述

### 1.1 应用名称
智能回复助手
\n### 1.2 应用类型
iOS原生应用
\n### 1.3 应用描述
一款基于iOS辅助功能的智能聊天回复助手，通过截图聊天记录快速生成个性化回复建议，帮助用户在社交场景中更高效地沟通。

---

## 2. 核心功能模块

### 2.1 用户登录模块
\n#### 2.1.1 登录方式
- 支持微信登录\n- 支持手机号登录
- 用户可自由选择任一方式完成登录注册
\n#### 2.1.2 登录流程
- 首次登录用户需完成注册流程
- 已注册用户直接登录进入应用
- 登录成功后根据用户状态跳转至对应页面

---

### 2.2 首页逻辑模块
\n#### 2.2.1 首次用户流程
- 首次登录用户默认进入问卷填写页面
- 完成问卷填写后，系统自动构建用户画像
- 问卷提交后自动跳转至上传截图页面

#### 2.2.2 非首次用户流程
- 非首次用户登录后直接进入上传截图页面
- 可通过设置入口重新填写问卷更新画像

---

### 2.3 快捷截图触发模块

#### 2.3.1 截图触发方式
- 用户通过iOS自带辅助功能（小圆点/AssistiveTouch）一键截取聊天记录
- 截图操作可在任意聊天应用中执行
\n#### 2.3.2 截图后处理
- 截图完成后自动唤起智能回复助手应用
- 应用自动加载截图内容并进行分析
- 分析完成后展示回复建议页面

---

### 2.4 用户画像构建模块

#### 2.4.1 初始问卷设计
\n**问卷题目列表：**
\n1. **题目1：您是新用户吗？**
   - 选项：是 / 否
   - 逻辑：\n     - 选择是：继续填写后续问题（题目2-题目N）
     - 选择否：跳转至补充信息页面\n
2. **题目2：您的性别是？**
   - 选项：男 / 女 / 其他 / 不愿透露
\n3. **题目3：您的星座是？**\n   - 选项：白羊座 / 金牛座 / 双子座 / 巨蟹座 / 狮子座 / 处女座 / 天秤座 / 天蝎座 / 射手座 / 摩羯座 / 水瓶座 / 双鱼座

4. **题目4：您的性格偏向是？（可多选）**
   - 选项：外向 / 内向 / 理性 / 感性 / 严谨 / 随性 / 幽默 / 严肃\n
5. **题目5：您的MBTI性格类型是？**
   - 选项：INTJ / INTP / ENTJ / ENTP / INFJ / INFP / ENFJ / ENFP / ISTJ / ISFJ / ESTJ / ESFJ / ISTP / ISFP / ESTP / ESFP / 不清楚

6. **题目6：您在聊天时标点符号的使用习惯是？**
   - 选项：经常使用标点符号 / 偶尔使用标点符号 / 很少使用标点符号 / 几乎不使用标点符号

7. **题目7：您在聊天时的断句习惯是？**
   - 选项：喜欢长句子一次发送 / 喜欢短句子分多次发送 / 根据内容灵活调整\n
8. **题目8：您常用的语气词有哪些？（可多选）**
   - 选项：哈哈 / 呵呵 / 嗯嗯 / 啊 / 哦 / 嘛 / 呀 / 吧 / 啦 / 哒 / 其他（填空）

9. **题目9：您在聊天时的表情符号使用频率是？**
   - 选项：经常使用 / 偶尔使用 / 很少使用 / 几乎不使用

10. **题目10：您更倾向于使用哪种回复风格？**
    - 选项：简洁直接 / 详细解释 / 幽默风趣 / 温柔体贴 / 正式礼貌\n
#### 2.4.2 补充信息页面
- 当用户在题目1选择否时，跳转至补充信息页面
- 页面提供长文本输入框，用户可直接输入补充内容
- 输入内容示例：我是一个比较内向的人，喜欢用短句聊天，经常用哈哈和嗯嗯，不太喜欢用标点符号
- AI接收用户输入后，自动分析并更新用户画像
- 提交后跳转至上传截图页面

#### 2.4.3 特征分析与存储
- AI分析问卷结果，提取以下用户特征：
  - 性别信息
  - 星座信息
  - 性格特点（外向/内向、理性/感性等）
  - MBTI性格类型
  - 标点符号使用习惯
  - 断句习惯
  - 常用语气词
  - 表情符号使用频率
  - 回复风格偏好
- 将用户画像数据存储至数据库
- 问卷重新填写时，保留原有用户画像，仅更新新填写的内容

#### 2.4.4 持续学习优化机制
\n**学习数据来源：**
- 用户后续使用过程中的聊天场景
- 用户选择的回复内容
- 用户自定义的回复内容
\n**学习流程：**
1. 每次生成回复时，提供第四条回复选项为以上都不合适，我要自定义
2. 移动端直接展示文本框供用户填写，无需弹出窗口
3. 用户填写自定义回复后，系统记录该回复内容
4. AI分析自定义回复，提取语言习惯特征：
   - 标点符号使用频率和类型
   - 断句方式和长度偏好
   - 语气词使用习惯\n   - 表情符号使用情况
   - 回复风格特点
5. 根据分析结果更新用户画像
6. 在下一次聊天分析中应用学习到的新特征

**学习优化目标：**
- 使生成的回复越来越符合用户的真实语言习惯
- 提高回复的个性化程度
- 减少用户需要自定义回复的频率
\n---

### 2.5 智能回复生成模块

#### 2.5.1 对话角色识别

**识别规则：**
- 通过头像位置识别对话角色：\n  - 左侧头像发出的消息为对方（问题者）
  - 右侧头像发出的消息为用户本人（回答者）
- 用户本人的发言内容计入用户发言习惯和用户特征
- 对方的发言内容为需要被回答的内容
\n**特殊内容处理：**
- 合并转发内容：AI根据左右头像位置判断发送者身份
- 转发链接：AI根据左右头像位置判断发送者身份
- 图片消息：识别图片发送者，但不分析图片内容
- 语音消息：识别语音发送者，但不分析语音内容

#### 2.5.2 对方意图分析

**分析展示位置：**
- 在推荐回复上方增加AI分析区域
- 分析区域标题为对方想表达的内容
\n**分析内容：**
- AI综合分析对方所有发言\n- 识别对方可能涉及的多个问题
- 提取对方的核心意图和情绪
- 以简洁文字形式展示分析结果

**分析示例：**
- 对方在询问你周末是否有空，并希望约你一起吃饭看电影
- 对方在分享今天的工作烦恼，希望得到安慰和建议
\n#### 2.5.3 回复生成逻辑

**生成依据：**
- 用户画像数据（性别、星座、性格、MBTI、语言习惯等）
- 当前聊天内容和上下文
- 对方的意图分析结果
- 用户历史回复选择记录

**生成要求：**
- 精确分析用户的语言习惯，包括：
  - 标点符号使用频率和类型
  - 断句方式（长句/短句）
  - 语气词偏好
  - 表情符号使用习惯
- 针对对方的所有问题进行综合回答
- 生成的回复需符合用户的性格特点和回复风格
- 回复内容需自然流畅，避免生硬\n
**回复选项数量：**
- 生成3条符合用户风格的回复选项
- 第4条固定为以上都不合适，我要自定义

**回复展示形式：**
- 每条回复以独立卡片形式呈现
- 卡片采用圆角设计，圆角弧度为12-16px
- 卡片带有轻微阴影效果，增强层次感
- 选中回复时有高亮边框和轻微弹跳效果

#### 2.5.4 回复操作功能

**操作选项：**
- 一键复制：点击复制按钮，将回复内容复制到剪贴板
- 直接发送：点击发送按钮，自动跳转至聊天应用并粘贴回复内容（需调用iOS系统分享功能）
\n**自定义回复：**
- 点击第4条选项以上都不合适，我要自定义
- 移动端直接展示文本框，无需弹出窗口\n- 用户填写自定义回复后，可选择复制或发送
- 系统记录自定义回复内容，用于持续学习优化

---

### 2.6 历史记录管理模块

#### 2.6.1 历史记录存储
- 系统后台保存用户的历史聊天记录
- 系统后台保存用户的回复选择记录
- 历史记录用于持续优化用户画像
- 历史记录不对用户展示\n
#### 2.6.2 存储规则
- 默认保存最近100条历史记录
- 超过100条时，自动删除最早的记录
- 系统可根据存储空间自动调整保存条数

#### 2.6.3 数据安全
- 历史记录仅用于AI学习优化\n- 不对外泄露或分享用户数据
- 用户可在设置中选择清空历史记录

---

## 3. 技术实现要点

### 3.1 iOS辅助功能集成

#### 3.1.1 AssistiveTouch调用
- 调用iOS AssistiveTouch功能实现快捷截图
- 用户可在iOS系统设置中配置AssistiveTouch快捷操作
- 截图操作触发后，自动唤起智能回复助手应用\n
#### 3.1.2 应用唤起机制
- 截图后自动唤起应用界面
- 应用启动时自动加载最新截图\n- 加载过程中展示加载动画（3D球体旋转或渐变色波纹扩散效果）

---

### 3.2 图像识别技术
\n#### 3.2.1 文本识别
- 识别截图中的聊天文本内容
- 支持中文、英文及常见语言识别
- 识别准确率需达到95%以上

#### 3.2.2 对话上下文提取
- 提取对话上下文信息
- 识别对话时间顺序\n- 区分不同发言者的消息\n
#### 3.2.3 角色识别
- 通过头像位置区分对话角色：
  - 左侧头像为对方\n  - 右侧头像为用户本人
- 识别并处理合并转发内容
- 识别并处理转发链接

#### 3.2.4 特殊内容处理
- 识别图片消息（但不分析图片内容）
- 识别语音消息（但不分析语音内容）
- 识别表情符号和emoji
\n---

### 3.3 AI分析引擎

#### 3.3.1 用户画像构建
- 分析用户问卷，建立初始画像
- 提取用户性格特征、语言习惯等关键信息
- 将画像数据结构化存储至数据库

#### 3.3.2 意图分析
- 分析对方发言意图
- 识别多个问题并综合分析
- 提取对方的核心意图和情绪
\n#### 3.3.3 回复生成
- 根据用户画像和聊天内容生成个性化回复
- 精确分析语言习惯，包括：
  - 标点符号使用频率和类型
  - 断句方式和长度偏好
  - 语气词使用习惯
  - 表情符号使用情况\n- 生成3条符合用户风格的回复选项
\n#### 3.3.4 持续学习
- 持续学习用户行为和反馈
- 根据用户选择和自定义回复优化画像模型
- 提高回复的个性化程度和准确性

#### 3.3.5 性能优化
- 优化分析速度，提升响应效率
- 分析时间控制在3秒以内
- 确保用户体验流畅

---\n
### 3.4 数据存储与部署

#### 3.4.1 数据库选择
- 使用中国境内可访问的后端数据库服务
- 推荐选项：
  - 阿里云PostgreSQL数据库
  - 腾讯云PostgreSQL数据库
  - 其他国内云服务商的PostgreSQL数据库
\n#### 3.4.2 数据存储内容
- 用户画像数据\n- 用户历史选择记录
- 用户历史聊天场景记录
- 用户自定义回复记录
\n#### 3.4.3 AI API服务\n- 调用中国境内可用的AI API服务
- 推荐选项：\n  - 阿里云通义千问API
  - 腾讯云混元API
  - 百度文心一言API
  - 其他国内AI服务商的API
- 确保无需VPN即可正常使用

#### 3.4.4 数据安全
- 用户数据加密存储
- 数据传输采用HTTPS协议
- 定期备份数据，防止数据丢失\n\n---

## 4. 设计风格规范

### 4.1 配色方案

#### 4.1.1 主色调
- 采用渐变色彩，融合粉色、紫色、蓝色等柔和色调
- 营造梦幻科技感\n- 渐变方向：从左上到右下，或从上到下

#### 4.1.2 背景色
- 白色或浅色渐变背景
- 保持界面清爽\n- 避免使用过深的背景色

#### 4.1.3 文字颜色
- 主要文字：深灰色（#333333）或黑色（#000000）\n- 次要文字：中灰色（#666666）\n- 提示文字：浅灰色（#999999）
- 确保文字可读性

#### 4.1.4 强调色
- 紫色或粉色用于按钮、图标等交互元素
- 强调色需与主色调协调
- 用于引导用户注意力

---

### 4.2 视觉元素

#### 4.2.1 3D球体元素
- 在关键页面使用渐变色3D球体作为视觉焦点
- 关键页面包括：
  - 首页
  - 加载页\n  - 结果展示页
- 增强科技感和未来感
- 球体可带有旋转或漂浮动画效果

#### 4.2.2 图标风格
- 采用线性图标\n- 搭配渐变填充\n- 保持视觉统一性
- 图标线条粗细为2px

#### 4.2.3 圆角设计
- 界面元素采用圆角设计
- 圆角弧度为12-16px\n- 营造柔和友好的视觉体验
- 按钮、卡片、输入框等均采用圆角\n
#### 4.2.4 卡片阴影
- 卡片式布局带有轻微阴影效果\n- 阴影参数：0px 2px 8px rgba(0, 0, 0, 0.1)
- 增强层次感\n- 避免阴影过重

---
\n### 4.3 界面布局

#### 4.3.1 卡片式布局
- 回复选项以独立卡片形式呈现
- 每个卡片包含回复内容和操作按钮
- 卡片之间间距为12px
\n#### 4.3.2 顶部导航栏
- 简洁明了，仅保留必要功能入口
- 导航栏高度为44px（iOS标准）
- 导航栏背景色为白色或浅色渐变
- 导航栏包含：返回按钮、页面标题、设置按钮

#### 4.3.3 底部操作区域
- 固定在页面底部\n- 方便用户快速操作\n- 底部操作区域高度为60px\n- 包含主要操作按钮（如复制、发送等）

#### 4.3.4 聊天界面设计
- 参考UIdesign2.jpg的设计风格
- 左右分栏展示对话内容
- 左侧为对方消息，右侧为用户本人消息
- 消息气泡采用圆角设计\n- 对方消息气泡为浅灰色，用户消息气泡为渐变色
\n---

### 4.4 交互动效

#### 4.4.1 页面切换动画
- 采用从下向上的滑入动画
- 动画时长为300ms
- 使用缓动函数：ease-in-out
\n#### 4.4.2 按钮反馈效果
- 点击时有轻微的缩放效果（缩放比例为0.95）
- 点击时有颜色变化效果（颜色加深10%）
- 反馈时长为100ms

#### 4.4.3 加载动画
- 使用3D球体旋转效果
- 或使用渐变色波纹扩散效果
- 加载动画循环播放，直到内容加载完成

#### 4.4.4 回复选择效果
- 选中回复时有高亮边框（边框颜色为强调色）
- 选中回复时有轻微弹跳效果（弹跳高度为5px）
- 效果时长为200ms

---

### 4.5 应用Logo

#### 4.5.1 Logo文件
- 使用logo1.jpg作为应用图标
- Logo需制作多种尺寸以适配不同场景
\n#### 4.5.2 Logo应用位置
- 启动页：居中展示，尺寸为200x200px
- 导航栏：左上角展示，尺寸为32x32px
- 关于页面：居中展示，尺寸为120x120px
- 应用图标：iOS标准尺寸（1024x1024px）

#### 4.5.3 Logo显示要求
- 确保Logo在不同尺寸下保持清晰度
- 确保Logo在不同背景下保持识别度
- Logo周围需留有适当的留白空间

## 5. 页面结构与流程

### 5.1 启动页\n- 展示应用Logo（logo1.jpg）
- 展示应用名称：智能回复助手
- 背景使用渐变色\n- 停留时长为2秒
\n### 5.2 登录页
- 展示应用Logo和名称
- 提供微信登录按钮
- 提供手机号登录按钮\n- 底部展示用户协议和隐私政策链接

### 5.3 问卷填写页
- 顶部展示进度条，显示当前填写进度
- 每页展示1-2个问题
- 底部提供上一步和下一步按钮
- 最后一页提供提交按钮
- 提交后自动跳转至上传截图页面

### 5.4 补充信息页
- 顶部展示页面标题：补充信息\n- 中间展示长文本输入框\n- 输入框提示文字：请描述您的语言习惯和性格特点
- 底部提供提交按钮
- 提交后自动跳转至上传截图页面\n
### 5.5 上传截图页
- 顶部展示页面标题：上传截图
- 中间展示上传区域，提示用户使用AssistiveTouch截图
- 截图后自动加载并跳转至分析页面
\n### 5.6 分析页面
- 展示加载动画（3D球体旋转或渐变色波纹扩散效果）
- 显示分析进度提示：正在分析聊天内容...
- 分析完成后自动跳转至回复建议页面
