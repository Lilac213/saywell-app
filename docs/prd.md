# 智能回复助手需求文档

## 1. 应用概述

### 1.1 应用名称
智能回复助手
\n### 1.2 应用类型
iOS原生应用

### 1.3 应用描述
一款基于iOS辅助功能的智能聊天回复助手，通过截图聊天记录快速生成个性化回复建议，帮助用户在社交场景中更高效地沟通。

## 2. 核心功能

### 2.1 首页逻辑
- 首次用户：默认进入问卷填写页面
- 非首次用户：默认进入上传截图页面
- 首次填写完问卷后，系统自动更新用户画像，并跳转到上传截图页面
\n### 2.2 快捷截图触发
- 用户通过iOS自带辅助功能（小圆点/AssistiveTouch）一键截取聊天记录
- 截图后自动弹出应用页面，展示回复建议
\n### 2.3 用户画像构建
\n#### 2.3.1 初始问卷
- 首次使用时引导用户填写问卷
- 问卷包含以下内容：
  - 第一题：您是新用户吗？
    - 选择'是'：继续填写后续问题
    - 选择'否'：跳转至补充信息页面（提供长文本输入框，用户可直接输入补充内容，AI接收后更新用户画像）
  - 性别信息\n  - 星座信息
  - 性格偏向问题（提供多个选项供用户选择，如：外向/内向、理性/感性、严谨/随性、幽默/严肃等）
  - MBTI性格类型
  - 语言习惯相关问题（如：标点符号使用习惯、断句习惯、常用语气词等）
  - 其他个性特征识别问题

#### 2.3.2 特征分析与存储
- AI分析问卷结果，提取用户特征
- 将用户画像数据存储至数据库
- 分析内容包括：性别、星座、性格特点、语言习惯（含标点符号、断句习惯）、人格特征等
- 问卷重新填写时，保留原有用户画像，仅更新新填写的内容

#### 2.3.3 持续学习优化
- 在用户后续使用过程中，不断收集聊天场景和用户选择的回复\n- 每次生成回复时，提供第四条回复选项为'以上都不合适，我要自定义'，移动端直接展示文本框供用户填写，无需弹出窗口
- 根据用户反馈和自定义内容，更新用户画像（包括语言习惯、标点符号使用、断句偏好等）
- 在下一次聊天分析中应用学习到的新特征

### 2.4 智能回复生成
\n#### 2.4.1 对话角色识别
- 通过头像位置识别对话角色：左侧头像发出的消息为对方（问题者），右侧头像发出的消息为用户本人（回答者）
- 用户本人的发言内容计入用户发言习惯和用户特征
- 对方的发言内容为需要被回答的内容
- 特殊处理：合并转发内容和转发链接，AI根据左右头像位置判断发送者身份

#### 2.4.2 对方意图分析
- 在推荐回复上方增加AI分析区域，展示对方想表达的内容和意图
- AI综合分析对方所有发言，识别可能涉及的多个问题
\n#### 2.4.3 回复生成
- 基于用户画像和当前聊天内容，AI生成多个符合用户风格的回复选项
- 精确分析用户的语言习惯，包括标点符号使用频率、断句方式、语气词偏好等
- 针对对方的所有问题进行综合回答
- 用户可从多个回复建议中选择合适的内容
- 支持一键复制或直接发送回复

### 2.5 历史记录管理
- 系统后台保存用户的历史聊天记录和回复选择，用于持续优化用户画像
- 历史记录不对用户展示\n- 历史记录保存条数可由系统自动管理（默认保存最近100条）

## 3. 技术要点

### 3.1 iOS辅助功能集成
- 调用iOS AssistiveTouch功能实现快捷截图
- 截图后自动唤起应用界面
\n### 3.2 图像识别\n- 识别截图中的聊天文本内容
- 提取对话上下文信息
- 通过头像位置区分对话角色：左侧头像为对方，右侧头像为用户本人
- 识别并处理合并转发内容和转发链接

### 3.3 AI分析引擎
- 分析用户问卷，建立初始画像
- 根据用户画像和聊天内容生成个性化回复
- 分析对方发言意图，识别多个问题并综合回答
- 精确分析语言习惯，包括标点符号、断句、语气词等细节特征
- 持续学习用户行为和反馈，优化画像模型
- 优化分析速度，提升响应效率

### 3.4 数据存储与部署
- 存储用户画像数据\n- 记录用户历史选择和聊天场景
- 使用中国境内可访问的后端数据库服务（如阿里云PostgreSQL数据库、腾讯云PostgreSQL数据库等）
- 调用中国境内可用的AI API服务（如阿里云通义千问API、腾讯云混元API、百度文心一言API等），确保无需VPN即可正常使用

## 4. 设计风格

### 4.1 配色方案
- 主色调：采用渐变色彩，融合粉色、紫色、蓝色等柔和色调，营造梦幻科技感
- 背景色：白色或浅色渐变背景，保持界面清爽\n- 文字颜色：深灰色或黑色，确保可读性
- 强调色：紫色或粉色用于按钮、图标等交互元素

### 4.2 视觉元素
- 3D球体元素：在关键页面（如首页、加载页、结果展示页）使用渐变色3D球体作为视觉焦点，增强科技感和未来感
- 图标风格：采用线性图标，搭配渐变填充，保持视觉统一性
- 圆角设计：界面元素采用圆角设计，圆角弧度为12-16px，营造柔和友好的视觉体验
- 卡片阴影：卡片式布局带有轻微阴影效果，增强层次感

### 4.3 界面布局
- 采用卡片式布局，回复选项以独立卡片形式呈现\n- 顶部导航栏简洁明了，仅保留必要功能入口
- 底部操作区域固定，方便用户快速操作
- 聊天界面参考UIdesign2.jpg的设计风格，左右分栏展示对话内容

### 4.4 交互动效
- 页面切换：采用从下向上的滑入动画\n- 按钮反馈：点击时有轻微的缩放和颜色变化效果
- 加载动画：使用3D球体旋转或渐变色波纹扩散效果
- 回复选择：选中回复时有高亮边框和轻微弹跳效果

### 4.5 应用Logo
- 使用logo1.jpg作为应用图标
- Logo应用于启动页、导航栏、关于页面等位置
- 确保Logo在不同尺寸下保持清晰度和识别度
